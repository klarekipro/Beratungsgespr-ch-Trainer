## Что изменено

- `header_menus.js/css` стал общим компонентом для шапки обеих ролей и всех обычных одиночных select, включая страницу входа. Те же поверхность/зелёная палитра/caret/галочка/hover/focus; listbox/option для выбора значения и menu/menuitem для действий. Исходные поля скрыты, остаются в форме с прежними ID/name/data-атрибутами и обработчиками input/change. Отражаются disabled/fieldset, выбранное значение и ошибки. Наблюдатель обслуживает динамические формы. Меню «Weitere Aktionen» конструктора также использует общий компонент, сохраняя исходные команды/импорт. Раскрывающиеся разделы не превращены в меню.
- Клавиатура Enter/Space, стрелки/Home/End, Tab/Escape, поиск по первым буквам. Одновременно один список; внешнее нажатие закрывает без отмены исходного действия. Возврат фокуса работает и после обновления панели категории. Портал избегает clipping; категория ограничена боковой панелью и окном, длинные строки переносятся, длинный список прокручивается. По умолчанию вниз/справа, при недостатке места — вверх.
- В беседе товар открывается отдельно от сравнения. Видимая подпись «Добавить к сравнению», кнопка «Сравнить (N)», подсказка при одном товаре. Ограничения 2–3 одной категории и снятие выбора сохранены. Пустой каталог показывает объяснение без фильтра/поиска. Аналогичный фильтр компании использует общий компонент.
- Исторический блок переименован в «Справочник этой беседы», свёрнут, объяснение видно сразу. Фокусная рамка только после клавиатуры и при focus-visible; после ухода фокуса рамки нет. Для материалов используется прежний снимок и сохранённая компания, без подстановки текущего каталога.
- Нейтральные метки отчёта, номера этапов и символ получили тематические пары фона/текста. Цветные статусы сохранены. Язык экспорта — общий список, прежний обработчик/параметр language. DE/EN/RU.

Backend меняет только VERSION; voice.js, Actor, workflow, app.js, данные материалов и рабочие снимки не менялись.

# Карта экранов и переходов

Все обычные кадры — 1440×900, Deutsch. `full` — полная высота документа при той же ширине. На стенде хост `localhost:8101`, в рабочем приложении — `127.0.0.1:8100`. Номера не обозначают обязательную последовательность работы пользователя.

| Кадры | Экран / состояние | Переход |
|---|---|---|
| 01, 02 | Тренировка: первый экран / вся страница, 6 заданий | `/learner#learner/practice` → боковое меню **Training** |
| 03, 04, 29 | Активная DE-беседа: верх, раскрытый блок отсутствующих материалов, полный обзор | **Fortsetzen** → `#learner/session/reference-session-28` → **Materialien dieser Versuchsversion** |
| 05, 06 | История: верх / вся страница, фильтры и статусы | Боковое меню **Meine Gespräche** → `#learner/history` |
| 07, 08, 09 | Существующий отзыв сотруднику: верх / вся страница / нижний экран при scrollY=880 | История → **Bericht** → `#learner/session/reference-session-27` |
| 10 | Справочник: компания | **Über das Unternehmen** → `#learner/company` |
| 11, 12 | 18 товаров: верх / полный список | В справочнике → **Produkte** |
| 13 | Поиск `LH-BO-103`, раскрытая карточка | **Suchen** → **Klar Weiß 60** |
| 14, 15 | 9 услуг: верх / вся таблица | **Servicepreisliste** |
| 16 | Условия, раскрыт **Einbau und Kompatibilität** | **Arbeitsbedingungen** → нужная тема |
| 17, 18 | Документы, раскрыт **Interne Regeln**: верх / весь текст | **Dokumente** → **Interne Regeln** |
| 19 | Очередь наставника: ожидающие проверки | `/mentor#mentor/reviews` → **Gespräche prüfen** |
| 20, 21, 22, 23 | Существующий проверенный разговор: верх / весь разбор / середина / форма отзыва | Очередь → **Mit Feedback** → **Öffnen**, `#mentor/review/reference-session-27`; прокрутка 880 и 1760 px для кадров 22–23 |
| 24 | Компактный конструктор: все основные группы закрыты | **Kundenstudio** → `#mentor/personas` → существующий профиль → **Ansichtseinstellungen** → **Dichte: Kompakt** |
| 25 | Конструктор: основные сведения раскрыты | **Grunddaten und Verfügbarkeit** |
| 26, 27 | Конструктор: список фактов, верх / вся страница | **Fakten, Bedarf und Grenzen** |
| 28 | Конструктор: одна карточка факта раскрыта | **Какое оборудование и какой результат нужны**; подпись авторская, сохранена на русском |

В интерфейсе доступны действия запуска, анализа, завершения, публикации, сохранения версии, сертификата и экспорта. Для кадров эти действия не выполнялись. Настройка плотности и автоматическая отметка показанного отзыва меняли только обезличенную копию.

Недоступное состояние «активная беседа + новый справочник A17» описано в README; кадр 04 документирует отсутствие каталога, а не изображает новый справочник внутри старой беседы.

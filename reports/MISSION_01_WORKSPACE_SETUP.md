## Безопасность

`.env` не копировался, не создавался, ключ не переносился автоматически. `.env.example` содержит пустое поле ключа и имя модели; файл допустим для Git. Непустых API-ключей в документации или логах нет.

В `.gitignore` исключены `.env`/`.env.*` с исключением шаблона, виртуальные окружения Python, кэши, локальные БД, приватные ключи, логи и временные файлы. Отдельно исключены все `results.json`, `*.jsonl`, run-каталоги архива, `reports/private/`, raw/transcripts.

Проведены 13 проверок поведения `git check-ignore --no-index`: локальные конфигурации, виртуальное окружение, Python/pytest cache, SQLite/DB, log/tmp, сырые результаты и приватный каталог игнорируются; `.env.example` не игнорируется. Все прошли.

Файлы нового workspace просканированы на совпадение с известными значениями секретов из текущего окружения и исходного локального конфига, без вывода значений. В подготавливаемых для commit файлах дополнительно проверены типичные шаблоны OpenAI/GitHub/AWS токенов и заголовки приватных ключей; совпадений не найдено. Индекс Git отдельно проверен на чувствительные пути и содержимое. Это конкретные выполненные проверки, не гарантия универсального обнаружения всех возможных секретов.

**Семь скопированных файлов намеренно остаются вне Git:** исходный сырой `results.json`, оба файла run-001 и четыре файла run-002. Они физически присутствуют локально и включены в SHA-256-манифест. Остальные 11 файлов исследовательского архива допустимы для первого commit: код, синтетические эталоны, отчёты и метаданные проверки. Сырые API-ответы содержат синтетические диалоги, но выбран консервативный режим локального хранения.

Закоммиченные отчёты содержат примеры только синтетического клиента Herr Krüger. Будущие реальные клиентские данные и персональные диалоги нужно оставлять в приватных результатах и не добавлять в эти отчёты.

## Git

Инициализирован **отдельный локальный Git-репозиторий**, ветка `main`; конфигурация имени/почты автора доступна. Создан первоначальный локальный commit с сообщением `chore: initialize Beratungsgespraech-Trainer workspace`. Состав индекса проверен до commit, после commit проверен состав дерева: секреты и сырые API-результаты не включены. SHA commit доступен через `git log -1 --oneline` и указан в итоговом сообщении; в самом отчёте hash собственного commit не дублируется.

Новый GitHub-репозиторий не создавался, push не выполнялся. Пользователь сообщил о существующем репозитории с тем же названием; через доступный GitHub-поиск он не найден. Уточнение URL отправлено пользователю. Пока точный адрес не получен, `origin` не назначен: ни исходный Train Today remote, ни предположительный URL не подставлялись. Подключение существующего remote остаётся отдельным уточнением, не препятствующим локальной приёмке MISSION 01. До отдельного разрешения запрет push сохраняется.

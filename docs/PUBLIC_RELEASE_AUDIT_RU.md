## Как продолжить с сохранением истории

1. Наименее разрушительный вариант: владелец подтверждает конкретные ФИО, аккаунты, диалоги, отзывы, сертификат и author/committer e-mail как разрешённые к PUBLIC показу; для чужих реальных данных нужно соответствующее основание. Затем завершить просмотр исторических binary assets и выбрать текущие скриншоты. Разрешение только PRIVATE не переносить автоматически.
2. Если что-то нельзя раскрывать: сохранить оригинальную полную историю и assets приватно. Для обезличенного публичного варианта потребуются новые медиа с новыми SHA-256 и отдельное решение об очистке Git history / отдельном публичном наборе. Эти действия меняют текущие ограничения владельца и сейчас НЕ выполняются.
3. При запрете и на раскрытие, и на изменение истории существующий репозиторий должен остаться PRIVATE. Публичный репозиторий не может одновременно скрывать доступные через его историю/Release оригиналы. Commit удаления текущих файлов этого не решает.

v0.15.3 и оба фильма/ZIP сохранены с прежними SHA-256; суммы перечислены в `releases/v0.15.3-SHA256SUMS.txt`. Public-история не переписывалась. Прежние backup/bundle остаются приватными. DATA-001 и AI-quality issues не исправлялись.

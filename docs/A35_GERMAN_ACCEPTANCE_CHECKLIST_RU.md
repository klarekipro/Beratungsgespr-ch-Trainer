## Подготовка

- Сохранить несохранённые поля в открытых вкладках. Если приложение на8100 работает, просто открыть [кабинет сотрудника](http://127.0.0.1:8100/learner); запускать start повторно не требуется.
- Использовать существующую активную учётную запись `alex` / Alex и свой существующий аккаунт наставника; пароли в документах не хранятся. Удобно сотрудник в одном браузере/профиле, наставник — в другом: разные вкладки одного профиля делят cookie и могут менять активный аккаунт друг другу.
- Для обеих ролей выбрать **Deutsch** как язык интерфейса. Язык тренировки и диктовки выбирать отдельно. Если сервер остановлен, запуск — по разделу эксплуатации [freeze report](A35_RELEASE_FREEZE_RU.md); оператор перед вмешательством создаёт свежую backup API.
- Зафиксировать дату, браузеры, версию `0.15.1-certificate-issuer`, текущую ссылку и результат каждого шага. Не записывать пароли/ключи/содержимое cookies. Не считать технический статус ready подтверждением качества ИИ.

| 9 | Открыть `/mentor#mentor/reviews` в отдельном профиле/браузере | Найти нужного сотрудника фильтром и колонкой имени, затем точную новую попытку |

| 11 | Приватный mentor AI запускать **только если владелец сейчас явно решил оплатить этот запрос**; иначе открыть уже сохранённое или пропустить | Приватный разбор не публикуется сотруднику. При ошибке зафиксировать статус/время, перейти к ручной оценке |

## Сертификат — отдельная добровольная проверка

В freeze-снимке **7 черновиков и0 выданных** сертификатов. Поэтому пустой learner-раздел сертификатов сейчас ожидаем: наличие PDF с MUSTER не является выдачей.

1. Если реального решения о компетенции ещё нет — не выдавать сертификат ради заполнения экрана; достаточно проверить существующий preview. Если владелец принимает самостоятельное решение о выдаче, открыть «Сертификаты сотрудника» отдельно от публикации отзыва.
2. Ввести вручную **имя и фамилию получателя** и **имя и фамилию выдающего**. Логин не подставляется. Тема/комментарий/один выбранный язык отражаются дословно; авторский текст автоматически не переводится.
3. Проверить PDF-preview: оба имени, Unicode, MENTOR / AUSSTELLER, MUSTER/не выдан, без активного номера/UUID. «Изменить данные» возвращает оба поля без потери значений. Пустое/одиночное имя не позволяет завершить выдачу.
4. Только по отдельному решению наставника нажать подтверждение. Проверить final PDF без watermark, с номером/датой; затем у получателя `/learner#learner/history/certificates`. Другой сотрудник не должен видеть этот документ. Не менять аккаунты ради теста на рабочей базе — неизменность ФИО после rename уже проверена на изолированных данных.
5. Если нужна печать: A4 landscape,100%, проверить поля и переносы. Safari и физическая печать ещё не подтверждены этой freeze-проверкой.

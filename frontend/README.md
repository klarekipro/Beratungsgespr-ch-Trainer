# Frontend — локальный тренажёр консультации

Функциональный интерфейс на HTML/CSS/JavaScript без сборки, внешних шрифтов или CDN. FastAPI обслуживает `index.html` на `/`, остальные файлы — на `/static/`. API и интерфейс работают на одном origin.

## Два рабочих пространства

- **Ученик:** выбор клиента и режима, история/продолжение беседы, вопросы и резюме, итоговое предложение, завершение, разбор, PDF/TXT/JSON, передача наставнику и просмотр отзыва.
- **Наставник:** карточка компании с услугами/условиями/ограничениями, источник и вставленный текст с сайта, создание/редактирование/удаление сценариев, скрытые факты и неопределённости, план вопросов, очередь отправленных бесед и письменная обратная связь.

Это два интерфейса одного локального владельца. Переключатель пространства и заголовок `X-Workspace-Role` не являются аутентификацией нескольких пользователей. API-ключ не вводится в интерфейс, не передаётся клиенту и не хранится в LocalStorage. LocalStorage содержит только предпочтение рабочего пространства.

## Режимы беседы

**Сценарный режим** явно обозначен: он использует ограниченный распознаватель и подготовленные ответы. Это техническая практика без AI-вызовов; свободная семантика и педагогический эффект не заявляются. Резюме в этом режиме нужно формулировать на основе фактических ответов клиента. Точные технические примеры находятся в `backend/app/dashboard/seeds.py` в `DEMO_WALKTHROUGH`; приватные ответы не показываются в активной ученической сессии.

**OpenAI** доступен для новой беседы только при серверной конфигурации. При ошибке API интерфейс сохраняет реплику для явного повтора и не переключает пользователя в сценарный режим. Фактическое качество модели требует отдельной проверки.

## Данные и поведение

- Каталог ученика и активный диалог используют публичные API views; полный сценарий загружается только в редакторе наставника.
- Версии карточек фиксируются сервером для каждой беседы. Редактирование компании или сценария не переписывает старую попытку.
- Повтор отправки сообщения использует тот же `request_id`; после конфликта версии загружается актуальная беседа.
- Незавершённую попытку можно закончить с неполным результатом. Скрытые факты и экспорт появляются только после завершения.
- «Отправить наставнику» добавляет беседу во внутреннюю очередь, не отправляет email или сообщения во внешние системы.
- Вёрстка адаптирована для телефона, планшета и desktop. Используются системные шрифты, контрастный фокус, подписи полей, клавиатурная навигация и нативный диалог подтверждения завершения.

Контракт API: [DASHBOARD_API.md](../docs/implementation/DASHBOARD_API.md). Запуск сервера — по основной инструкции приложения. Открывать `index.html` через `file://` не нужно: интерфейсу требуется локальный Python-сервер.

## Быстрая проверка JavaScript

```sh
node --check frontend/app.js
```

Синтаксическая проверка не заменяет проверку интерфейса в браузере и реальных маршрутов API.

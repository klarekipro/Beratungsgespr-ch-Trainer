# Уровни проверок

- `unit/`: будущие детерминированные проверки Policy/State.
- `integration/`: будущие проверки границ компонентов; реальные LLM-результаты не подменяются заглушками.
- `evals/`: будущие смысловые проверки классификации, раскрытия, grounding и немецкой речи.

Сейчас проверяется только рабочее пространство командой `python3 scripts/check_workspace.py`. Исторические реальные проверки и эталоны сохранены в research, новых API-вызовов в MISSION 01 нет.

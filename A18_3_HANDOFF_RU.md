10.11.2026. Ветка `codex/a18-3-header-dropdowns`, основание `bcdcad6` (A18.2). Версия исходников `0.10.3-header-dropdowns`. Изменения не откатывают A18/A18.1/A18.2. Статус установки и SHA загруженного кода — в актуальной таблице PROJECT_STATE.md.

## Результат

- Общий компонент `frontend/header_menus.js/css`, только для сотрудника: оформление (light/dark/system), профиль (существующая форма пароля/logout), язык DE/EN/RU. Прямое открытие; никаких промежуточных панелей, системных select и крестиков для этих трёх контролов.
- Единые кнопки 40 px, иконки/caret, поверхности темы, зелёные состояния, selected/checkmark, видимый focus. Menu/menuitem/menuitemradio, aria-expanded/controls/checked, доступные подписи. Enter/Space, стрелки, Home/End, Tab и Escape.
- Один popup, открытие вниз под кнопкой с выравниванием справа. Портал внутри #app исключает clipping/inert в навигации активной беседы. У края окна позиция ограничивается; вверх только при недостатке места снизу. Выбор, повторная кнопка, Escape и внешний клик закрывают; внешний клик не перехватывает исходное действие.
- Тема применяет существующие переменные без перерисовки страницы, прежний пользовательский API и system listener сохранены. Записи настроек сериализованы. Язык использует прежнее сохранение и reload с подтверждением несохранённой работы; при записи есть существующий текст предупреждения о выходе.
- Logout сотрудника учитывает несохранённый черновик/заметки. Защита при записи, отмена, CSRF, пароль и фактический выход используют прежние механизмы.

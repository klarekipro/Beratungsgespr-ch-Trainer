## Исправление

Убран свободный ввод моделью пары path/quote для новых доказательств материалов. В wire-схеме `material_evidence` выбирает только path из enum строковых полей **того же исторического payload**. Сервер строго проверяет форму/путь и подставляет точное полное значение выбранного поля, затем выполняет каноническую проверку. Это чтение источника, без угадывания, нормализации или принятия выдуманной цитаты. Для этой попытки доступно 119 путей; схема 8798 символов. Материалы не дублируются в запросе, данные по-прежнему 29372 символа, все 17 сообщений передаются.

Сохранённый формат path+quote не меняется. supported/contradicted требуют источника; неизвестный путь, лишний модельный quote, отсутствие доказательства, неверная цитата и превышение числа ссылок отклоняются. Новые причины различаются: material_unknown_path, material_fields, material_required, material_count, material_quote_too_short, material_quote_mismatch с путём claim_checks/N/material_evidence/M; они доступны только внутренней диагностике. Серверная подстановка полного исходного поля может дать более длинную цитату в свёрнутом разделе материалов. Семантическую уместность выбранного источника по-прежнему оценивает модель/наставник: наличие цитаты само по себе не доказывает вердикт.

После неудачного обновления UI вместо «Auswertung gespeichert» явно показывает **«Vorherige Auswertung — die Aktualisierung ist fehlgeschlagen»**, с DE/EN/RU переводами. Старое состояние attempt_status=error уже достаточно, миграция не нужна. Очистка групп ссылок превращает `([1], , [4])` в `([1], [4])`; точные внутренние ссылки/цитаты и «Посмотреть» сохраняются, записи не переписываются.

Actor, его провайдер/промпт и поведение не менялись. Полный транскрипт, исторические условия, приватность, ручная отправка, рекомендация со ссылками на выводы и требование пробела для повтора сохранены. Один вызов, предел входа 65000, выход 3500, без retry/новых вызовов.

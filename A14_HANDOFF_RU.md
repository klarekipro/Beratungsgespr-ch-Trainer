# A14 — локализация учебных материалов и немецкая демонстрация

База: A13, `cdef078cf8daec8b1b69a4ea45447140b69a1ff7`.
Ветка: `a14-material-localization`. Отдельный worktree: каталог `app` в рабочем каталоге A14. Слияние не выполнялось, main не изменялся.

## Изменения

- `materials/source.ru.json` фиксирует оригиналы A13. `de.json` содержит публичные материалы, полные немецкие версии трёх заданий и подписи характеров; `en.json` — английские публичные материалы и подписи. Русские варианты берутся из оригиналов.
- В каталоге заданий, списках библиотеки и карточке компании язык публичных материалов следует DE/EN/RU интерфейса. Названия характеров переводятся только при совпадении с поставляемым оригиналом.
- «Язык интерфейса» и «Язык тренировки / Trainingssprache» явно разделены. Язык тренировки выбирается перед запуском, сохраняется отдельно в этом браузере и не переключается вслед за интерфейсом. Для встроенных примеров доступны DE/RU; английский здесь — язык интерфейса и публичных материалов.
- Новая немецкая беседа получает немецкие вступление, имя клиента, факты, подписи фактов и подсказки. Компания также копируется на немецком, если её оригинал не изменён. Снимок профиля и снимок задания согласованы. В выборе сохраняются язык тренировки и версия материалов A14.
- Перевод разрешён только при совпадении с замороженным оригиналом, включая ревизию. При сравнении учитываются значения необязательных полей по умолчанию: отсутствие старого `material` равнозначно `true`. Правки наставника не заменяются встроенными переводами. Изменённое задание запускается на авторском языке; недоступный перевод API отклоняет.
- Редакторы наставника продолжают работать с авторским исходником, чтобы просмотр перевода и последующее сохранение не перезаписывали оригинал. Переводы — отдельные представления, не миграция документов.
- Существующие беседы, их снимки, сообщения и отчёты не переводятся и не перезаписываются. API дополнительно сообщает сохранённый язык задания без изменения документа.
- Движок OpenAI, промпты, провайдеры и проверки ответов не изменялись.

## Исправление кэширования после запуска в обычном Chrome

Подтверждено расхождение профилей: обычный Chrome — `Default / Serhii`, окно автоматизации — отдельный `ms-playwright-mcp` с собственным каталогом данных и кэшем. На порту 8100 один сервер и одна база. В обычном профиле до исправления обнаружен точный `app.js` A13 (`cdef078`), SHA-256 `2858cfedcf56bbbdc2b3d959a5fadcd089868a085e5bc4230976b0fd7719b4bc`. В профиле автоматизации загружен A14, SHA-256 `d48d439a22e0deb9a683f4e1fbc3b74434dd9a0e78fcac5222ce5287afa9fafe` (также проверен исходник исполняемого скрипта через Debugger).

Причина: `/static/*` не имел явного Cache-Control, а адреса JS были неизменными. Свежий HTML и API не исключали повторное использование старого `app.js`. A13 показывает исходные русские `/api/scenarios` и не делает A14-запрос `/api/materials`.

В обычном профиле локальная диагностика с действующей сессией подтвердила тот же ID сотрудника, что и в окне автоматизации, `locale=de`, сохранённый язык интерфейса `de`, отсутствие service worker. `/api/scenarios` в обоих случаях содержит авторские русские оригиналы; `/api/materials` возвращает немецкие публичные варианты. До A14 в обычном профиле отдельного сохранённого выбора языка тренировки не было; профиль автоматизации использует DE. Язык тренировки не управляет переводом карточек.

Исправление: HTML входа и порталов содержит версионированные ссылки на CSS/JS. Общий отпечаток вычисляется из содержимого frontend, включая каталоги переводов; загрузчик переносит его на динамические voice.js, mentor_studio.js и app.js. Для `/static/*` добавлен `no-cache, max-age=0, must-revalidate`; HTML и API сохраняют `no-store`. Отпечаток доступен в meta HTML, заголовке `X-Trainer-Frontend-Revision` и привилегированном runtime. Поэтому обычное новое открытие URL обходит ранее сохранённые URL A13; очистка профиля, cookie и паролей не требуется.

Точечная проверка временной базы: HTML обоих порталов/входа содержит версии; динамический загрузчик их сохраняет; ответы статики требуют перепроверки; полученный app.js побайтно равен A14. Массовые тесты и запросы к OpenAI не выполнялись.

## Запуск

Из основной папки открыть `START_TRAINER.command` либо выполнить:

```sh
./START_TRAINER.command --no-browser
```

Эквивалент для установленного окружения: `.venv/bin/python scripts/local_installation.py start --no-browser`. Штатный launcher использует `.venv`, Keychain и прежнюю базу, проверяет экземпляр на 8100. Уже работающий сервер в этой задаче не останавливался и не запускался заново.

Ключ — в macOS Keychain; штатный механизм передаёт его серверу через анонимный pipe. Не копировать ключ в командную строку, документы, Git или браузер. Вход наставника/сотрудника осуществляется собственными аккаунтами; общих паролей нет. `SETUP_MENTOR.command` предназначен для первичной настройки, `RECOVER_MENTOR.command` — для явного восстановления владельцем. В этой задаче они не запускались.

`UPDATE_TRAINER.command` меняет установку и не нужен для обычного старта. Обновление, применение `scripts/prepare_a17_materials.py` и восстановление базы не выполнять как диагностические команды. Сервер слушает только loopback; для другого компьютера нужен отдельно согласованный защищённый доступ к единому экземпляру и базе.

## Принятые решения

- Сохранять OpenAI Simple Actor и границу клиентского контекста: без карточки продавца, внутреннего каталога и рубрикатора. Новые тренировки используют `simple_actor`; старые режимы остаются историей. Локальные проверки не доказывают общую смысловую безошибочность модели.
- Не использовать процентные оценки. ИИ-разбор — предварительный, ручное решение наставника хранится отдельно. Завершение, явная отправка, проверка и коммерческий исход не равнозначны.
- Сертификат выдаёт наставник отдельным действием с подтверждением, получателем остаётся владелец беседы; отзыв/замена сохраняют историю.
- DE/EN/RU интерфейс независим от языка тренировки; A14.1 добавил английскую тренировку. Встроенные переводы применяются только к согласованному оригиналу. Авторские изменения и существующие беседы не переводятся автоматически.
- A17: пять разделов справочника — компания, товары, прейскурант, условия, документы. Сотрудник читает справочник; технический импорт доступен наставнику. Поиск и навигация сохраняют черновик сообщения.
- Импорт проходит извлечение, сопоставление/исправление, предпросмотр и явное применение. Публикация карточки/материалов атомарна, устаревший preview отклоняется. Служебные связи сохраняются по ID/артикулу/точному названию; нечёткого угадывания нет. Неизвестная цена не превращается в ноль.
- `main` не менять, слияния не выполнять; работать и коммитить в рабочей ветке после минимальной проверки. Push — только по отдельному поручению. После каждой задачи обновлять этот документ.

## Ограничения и незавершённая приёмка

- **Содержательная приёмка A15 открыта.** Владелец должен оценить реальные разборы и длинные диалоги, включая отказ по промышленной газовой печи и отложенный выбор. Подставные ответы в тестах и успешный запуск не подтверждают качество анализа. Для старых бесед без снимка показывается `legacy_fallback_not_original`, это не исходное задание.
- **A16:** пользовательская оценка удобства владельцем остаётся открытой. Проверка обычного Chrome в A16 была ограничена инструментом; полноценная UI-проверка выполнялась в отдельном контексте на копии базы. Проверки A17 на копии и зафиксированный просмотр установленного интерфейса не закрывают автоматически приёмку A15/A16.
- **A17:** реализован и технически проверен справочник/импорт; нужны собственная сверка материалов владельцем и содержательная пользовательская приёмка. В A17 платные диалоги, анализы и переводы не запускались. В A14.1 были только два настоящих EN-хода — это не общая приёмка Actor.
- Импорт: UTF-8 MD/TXT, CSV, XLSX с одним листом и сохранёнными значениями формул. PDF требует текстового слоя и локального Poppler `pdftotext`; OCR и автоматического распознавания колонок PDF нет. Сканированный/пустой/защищённый PDF не считается успешным импортом.
- Для будущих произвольных документов автоматический перевод и редактор переводов не добавлены; отсутствие перевода обозначается явно. Переключение языка не запускает платный перевод.
- Физический микрофон, Safari, менеджер паролей владельца, реальные длинные комментарии/печатные имена, печать и рабочая процедура отзыва/замены сертификата требуют пользовательской проверки. Старые пункты про ручное создание двух сценариев из A15 следует сначала сверить с уже установленными сценариями Lindenhaus, не создавать дубликаты автоматически.
- Внешний сетевой доступ, email и push-доставка уведомлений не настроены. Прочтение отзыва фиксирует появление текста на экране, а не понимание человеком.
- Исторические проверки A17: 4 целевых теста, синтаксис JS/Python, diff и UI на копии базы прошли; предупреждение FastAPI/httpx TestClient сохранялось. Эти проверки в данной документационной задаче не перезапускались.
